# Clave quick start

**Keep passwords and API tokens out of your Python code.**

Clave is a local encrypted vault for development and test automation. It runs
on Python 3.10 or newer on Windows, macOS, and Linux.

## Install the beta

The developer beta is available on [TestPyPI](https://test.pypi.org/project/clave/0.2.0/).
In an active virtual environment, download the Clave wheel from TestPyPI and
install it with dependencies from your regular package index.

```console
python -m pip download --index-url https://test.pypi.org/simple/ --no-deps --only-binary=:all: clave==0.2.0
python -m pip install ./clave-0.2.0-py3-none-any.whl
clave --help
```

Use `0.2.1` in both commands after the [TestPyPI upload](https://test.pypi.org/project/clave/) completes.

## Save a credential and use it in Python

Run `clave --data-dir demo-vault` and choose **Save a credential**. Enter
`database.dev` for the name, `demo_user` for the username, and a fake password
for this exercise. The password prompt shows asterisks, and the first save
creates the vault. The same action is available as a direct command.

```console
clave --data-dir demo-vault store database.dev demo_user
```

From the same working directory, retrieve the credential in Python.

```python
from clave import Vault

vault = Vault(data_dir="demo-vault")
credential = vault.get("database.dev")
username, password = credential.username, credential.password
```

For an API token, use `clave --data-dir demo-vault secret store api_token.dev`
and retrieve it with `vault.get_secret("api_token.dev")`. Terminal reads show
metadata. Python returns the values for your application, so keep them out of logs.

## Check that you can recover your vault

Create a backup in a private folder and restore it into a fresh vault.

```console
clave --data-dir demo-vault backup demo-backup.clave
clave --data-dir restored-vault restore demo-backup.clave
clave --data-dir restored-vault doctor
clave --data-dir restored-vault list
```

Use a long, unique backup passphrase generated by a password manager and keep it
separate from the archive. Clave requires at least 12 characters. Choose a new
backup filename and an empty vault location for each rehearsal.

## Know what Clave protects

Clave encrypts saved values and stores the database and its key in separate
files. Anyone with both files can decrypt the records. Entry names and timestamps
are visible in the database. Keep the files private and out of Git.
